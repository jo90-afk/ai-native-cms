# Bootstrap — AI Native CMS

Status: **CONFIRMED**
Date: **2026-08-25 (America/New_York)**
Principal alias: `Repository Owner`

## Intake

Build a public-releasable version of an existing production CMS in this new repository. Use the platform-agnostic Lattice App Works runtime as the project-governance contract. Optimize the extraction so future general CMS features developed in an adopter/personal site can be adopted by the public version without expensive rewrites.

## Interpreted boundaries

- Production behavior is evidence, not a license to copy personal content or identifiers.
- Preserve path shape where practical to reduce future patch distance.
- Move site-specific values behind configuration/adapters rather than creating product forks.
- Keep anonymous delivery static-first and database-free.
- Preserve security and revision/provenance semantics during genericization.
- Public visibility and production deployment are not part of this bootstrap action.

## First objective

Establish the site-neutral foundation and prove that the generic runtime/schema can exist without personal-site constants before porting the remaining CMS surfaces.
